# Tic Tac Toe 🎮

A simple, classic two-player Tic Tac Toe game built with HTML, CSS, and JavaScript. Play locally with a friend on the same screen!

## ✨ Features

- **Two-Player Mode:** Player X and Player O take turns on the same device.
- **Instant Win & Draw Detection:** Automatically finds winning lines or a tie.
- **Restart Button:** Reset the board at any time to play again.
- **Lightweight & Fast:** Built with pure vanilla web technologies (no heavy frameworks).

---

## 🚀 Getting Started

Follow these quick steps to run the game locally on your computer.

### Prerequisites

You only need a standard web browser (like Chrome, Firefox, or Edge).

### Installation & Running

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```
2. **Navigate to the project folder:**
   ```bash
   cd tic-tac-toe
   ```
3. **Open the game:**
   Double-click the `index.html` file or open it directly in your web browser.

---

## 🛠️ Tech Stack

- **HTML5:** Structure of the game board and UI.
- **CSS3:** Styling, layout, and grid design.
- **JavaScript (ES6):** Game logic, turn tracking, and win-condition checks.

---

## 💡 How to Play

1. Player **X** always goes first.
2. Click on any empty square on the 3x3 grid to place your mark.
3. Players alternate turns until one player aligns 3 marks in a row (horizontally, vertically, or diagonally) or all squares are filled.
4. Click the **Restart** button to clear the board and start a new round.
